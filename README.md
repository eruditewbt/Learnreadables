## Overview

A document study workspace for reading, extracting, searching, analyzing, and discussing learning materials across common document and code formats.

## Who It Is For

Students, researchers, educators, and professionals working with large document collections.

## Capabilities

- Supports PDF, DOCX, TXT, Markdown, code, images, and presentation documents as described in the project
- Document extraction, analysis, and retrieval-assisted chat
- Study-content and question-generation workflows
- Local model and API-backed modes are represented in project documentation

## How To Use It

1. Install the project dependencies and configure required API/model settings
2. Start the documented application services
3. Upload or select a document and use its reading, analysis, or chat tools
